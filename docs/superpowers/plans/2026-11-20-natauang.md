# NataUang v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun 13 fitur keuangan harian iPhone dengan biaya admin terhubung, utang-piutang per orang, dan split bill manual/invoice dengan pembukuan opsional.

**Architecture:** Native SwiftUI, domain murni, satu jalur mutasi atomik melalui FinanceService dan persistence SwiftData. OCR menghasilkan draf transaksi atau invoice split; split hitung saja tidak membukukan uang. Penyimpanan lokal, backup portabel dan pengingat perangkat tanpa server.

**Tech Stack:** Usulan SwiftUI, SwiftData, Foundation, Vision, PhotosUI, UserNotifications, LocalAuthentication, CryptoKit, XCTest.

**Spec:** [Desain teknis](../specs/2026-11-20-natauang-design.md), [desain split bill](../specs/2026-11-20-split-bill-design.md), [PRD](../../PRD.md), [UX](../../../DESIGN.md).

Status: draft perencanaan, belum dieksekusi. F13 disetujui pengguna untuk masuk dokumentasi dan target v1; baseline D01–D05 tetap rekomendasi sampai gate S0-01. Eksekusi default di chat yang sama oleh agent utama; delegasi mengikuti otorisasi yang berlaku. Jangan mulai scaffolding hanya karena dokumen rencana selesai dibuat.

## Global Constraints

- Platform: iPhone, minimum iOS 17.
- Bahasa UI: Indonesia; mata uang: IDR; nominal: Int64 rupiah tanpa pecahan.
- Penyimpanan: lokal, tanpa akun/server dan tanpa unggahan gambar.
- Draf OCR tidak mengubah saldo sebelum konfirmasi pengguna.
- Seluruh perubahan transaksi terkait harus atomik dan idempoten.
- Split bill hitung saja tidak membuat transaksi atau utang; pembukuan eksplisit hanya menghitung bagian pribadi sebagai pengeluaran.
- Build, XCTest, simulator, dan validasi perangkat iOS memerlukan Mac/Xcode.

## Review Focus

1. Retry/double submit dan save gagal tidak menggandakan uang atau meninggalkan admin tanpa transaksi (S1-03, S2-02).
2. Utang lama, pembayaran sebagian dan penggantian split tidak menggandakan saldo/pengeluaran; termasuk mode teman membayar dan pembatalan pembukuan dengan relasi (S3-01, S3-02, S6-05).
3. Pergantian bulan/zona waktu tidak memindahkan transaksi antar periode; tanggal 31 dan jadwal setelah restore tetap konsisten (S4-02, S5-01).
4. OCR total/subtotal/item/pajak/service/diskon harus dikoreksi; pembagian termasuk sisa rupiah cocok dengan total, dan hitung saja tidak mengubah keuangan (S6-01–S6-04).
5. Kode pemulihan salah, relasi backup rusak dan kegagalan commit restore tidak mengubah store aktif atau membuka data terkunci (S7-01, S7-03).

## Cara menjalankan dan merekam verifikasi

S0-02 membuat scheme `NataUang`, target test `NataUangTests`/`NataUangUITests`, dan simulator bernama `NataUangTestDevice` dari runtime iOS terpasang yang kompatibel. Catat model, runtime, Xcode, SDK, dan deployment target di README. Perintah di bawah dijalankan pada Mac dari root, setelah S0-02:

```sh
xcodebuild -project NataUang.xcodeproj -scheme NataUang -destination 'platform=iOS Simulator,name=NataUangTestDevice' build
xcodebuild -project NataUang.xcodeproj -scheme NataUang -destination 'platform=iOS Simulator,name=NataUangTestDevice' test -only-testing:NataUangTests/MoneyTests
xcodebuild -project NataUang.xcodeproj -scheme NataUang -destination 'platform=iOS Simulator,name=NataUangTestDevice' test
```

Untuk setiap task ganti filter `NataUangTests/MoneyTests` dengan nama kelas test yang tertulis; dua kelas berarti dua `-only-testing:`. UI menggunakan target `NataUangUITests`. Lulus berarti exit code 0, seluruh test target benar-benar dieksekusi, tanpa skipped sebagai pengganti acceptance. Simpan ringkasan dan lokasi `.xcresult` di bukti; jangan commit data uji pribadi atau binary besar.

**Siklus tiap task implementasi:** test perilaku bernilai uang/invariant harus diamati gagal, implementasi minimum, test fokus lulus, review perubahan, bukti diperbarui, lalu commit kecil bila workflow git tersedia dan diizinkan. Task dokumentasi memakai review/check tautan sebagai pengganti test aplikasi. Pada Windows catat NOT RUN/blocked untuk pengujian iOS.
